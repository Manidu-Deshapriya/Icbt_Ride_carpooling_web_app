App Installation Guide

×

Android Guide

  • Open your browser.
  • Navigate to the web app's URL.
  • Look for an automatic pop-up prompt at the bottom.
  • Tap Add to Home screen if prompted.
  • Alternatively, tap the browser's menu icon (usually three dots or lines).
  • Select Install app or Add to Home screen.
  • Confirm the installation when requested.

iPhone Guide

  • Open your browser.
  • Navigate to the web app's URL.
  • Tap the Share button (the square icon with an upward arrow).
  • Scroll down the menu options.
  • Tap Add to Home Screen.
  • Type a custom name if desired.
  • Tap Add in the top right corner.
